# Schwarzschild Bondi-gauge presentation checks

These figures use the committed mostly-minus `psi0` fit at `M=1`, `r0=10`,
`ell_max=20`. The C++ diagnostics were generated by `bondi_plot_data`, and
the figures by `scripts/plot_bondi_checks.py`.

`lie_zeta_redshift_modes.pdf` shows 70 nonzero-`m` modes with `2 <= ell <= 8`.
It plots the worldline contraction `|u.zeta|`, the helical pullback
`|u^a u^b (L_zeta g)_ab|` at `omega=m Omega_phi`, and the same pullback at
`omega=m Omega_phi+0.004`. The maximum helical residual is `2.42e-19`;
the maximum detuned value is `3.93e-3`. The helical result follows from the
explicit `(m Omega_phi-omega)` factor in the circular-geodesic modal formula.
The detuned panel checks that the implementation does produce a finite signal
away from that identity. This is a check of the gauge-vector redshift
contraction, not an independent validation of the full metric.

`m_mode_held_collocation.pdf` compares the z-grid solution for the reduced
Held seed with the analytic Schwarzschild ell-sum for `m=2,3,4`, all with
`Nz=21`. The maximum relative complex seed errors are `9.30e-10`,
`5.44e-11`, and `8.33e-12`. The analytic seed's relative operator-equation
residuals are `1.92e-7`, `2.94e-8`, and `8.03e-9`. This validates the
ell-summed input and the m-mode Held seed inversion.

`adjusted_metric_radial_falloff.pdf` is the next Schwarzschild benchmark.
It uses the current `BondiGauge_Adjusted.nb` convention
`2 Re[Sdagger(Phi^Adj)] + Lie_zeta g`, with the fitted psi0 coefficients,
and sums the closed-form Schwarzschild `(ell,m)` components at fixed `m`.
Across 1,254 nonstationary radiative mode-components through `ell=20`, the
largest relative cancellation error in the `r` and constant Laurent
coefficients is `4.90e-16`. Direct finite-radius sums at `z=0.37` for
`m=2,3` show `h_nn`, `h_nm`, and `h_mm` approaching `1/r` from `r=20` to
`2000`; the plotted large-radius slopes range from `-1.003` to `-1.000`.
This is the independent modal reference for the **adjustment piece**.

`spectral_m_mode_metric_falloff.pdf` repeats the radial check using the
collocation-solved `+m` and `-m` Held seeds on the 21-point LGL z grid.
The reflected partner is the conjugate of the reduced `-m` seed; the angular
harmonics already supply the odd-`m` reflection phase. The C++ reconstruction
forms `Phi0H` through `Phi3H`, applies the spectral Held angular derivatives
for `Sdagger` and `Lie_zeta`, and sums their complex Laurent coefficients
directly at each radius. It does not project the solved seed back into
individual `ell,m` modes. At the interior node `z=0.3019898565`, the six
plotted `m=2,3` components have large-radius slopes between `-1.003` and
`-1.000`. Across all interior nodes, the largest relative difference from
the independent modal reference is `1.04e-6` for `m=2` and `1.54e-7` for
`m=3`; the largest relative residual in the growing and constant coefficients
is `2.24e-12`. This verifies the spectral m-mode operator chain for the
Schwarzschild circular-orbit adjustment. The original retarded Hertz metric
is not included in these figures.

The generic notes currently write a minus sign for the Lie term and flag
normalization discrepancies. This benchmark follows the plus sign and
factor of two in the current `BondiGauge_Adjusted.nb`, where the corresponding
Laurent cancellation was checked.

```sh
./build/bondi_schwarzschild_data_collocation_tests tests/data/psi0_schwarzschild_r0_10_lmax20_mostly_minus.csv plots/bondi_schwarzschild/spectral_metric_falloff.csv
/Users/antares/.pyenv/versions/mambaforge-4.10.1-4/envs/sage/bin/python scripts/plot_bondi_checks.py plots/bondi_schwarzschild
```

The last command uses the current machine's Sage environment, which includes
Matplotlib; any Python with Matplotlib can be substituted. The `.csv` files
are the direct C++ output; all figures are saved as PDF and PNG.
